# Occluded-Thermal-Detection

### 📂 Dataset
**FLIR Thermal Object Detection Dataset** (ADAS) for training and evaluation.
* **Source:** [FLIR ADAS Dataset (Roboflow)](https://universe.roboflow.com/thermal-imaging-0hwfw/flir-data-set)
* **Sensor Type:** LWIR (Long-Wave Infrared) Microbolometer (FLIR Tau 2).
